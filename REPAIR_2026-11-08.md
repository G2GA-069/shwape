## Fixed and verified against the live build

Deliverable `shwape-repaired.html` (live build + these three patches;
verified: all inline scripts parse, all pattern checks pass). Pending
deploy by owner via WhatIMade page editor, then drag the same file into
this repo as `index.html` to re-sync.

1. **Frame timing race — the production `startsWith` crash.**
   `frame(now)` now rejects malformed/negative deltas *before* the
   positive clamp. rAF timestamps and the watchdog's
   `performance.now()` can interleave out of order; one negative step
   regressed `Game.realT` and indexed before the sky palette, which is
   what threw in production.
2. **Sky-colour blending hardened.** `blend()`/`hex()` fall back to a
   default when a palette entry is missing instead of dereferencing
   `undefined`.
3. **KSC cache no longer poisons itself** (TECH_REVIEW BUG-4, actually
   fixed now). `checkedAt` is written only after a successful HTTP
   response and JSON parse; failed fetches retry next launch; non-OK
   HTTP throws instead of being parsed.

## Tooling constraints discovered

- The GitHub token used by the AI session lacks the `workflow` OAuth
  scope: it cannot create/modify files under `.github/workflows/`.
  CI must be added by the owner or a token with that scope.
- The same token writes whole files only; the ~540 KB single-file game
  cannot be written through it. Large changes ship as: patch script +
  owner upload, or owner grants a workflow-scoped token.
- A 5-test static smoke pack (`node --test`) and a ready CI workflow
  exist in the AI session's deliverables; land them with the next big
  update.

## Design invariant (author's rule, binding)

The game is opt-in. If the player chooses insult and domination, loss
is inevitable; the final authority — the disappointed mother, shame —
is unbeatable. **No change may add a conventional win state.** Insults
stay as-is.
