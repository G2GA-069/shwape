## Fixed and verified against the live build

Deliverable `shwape-repaired.html` (live build + these three patches;
verified: all inline scripts parse, all pattern checks pass). Pending
deploy by owner via WhatIMade page editor, then drag the same file into
this repo as `index.html` to re-sync. **Note: `shwape-v2.html` (Batch 1,
below) includes these three patches — deploying v2 makes the separate
repair deploy unnecessary.**

1. **Frame timing race — the production `startsWith` crash.**
   `frame(now)` now rejects malformed/negative deltas *before* the
   positive clamp. rAF timestamps and the watchdog's
   `performance.now()` can interleave out of order; one negative step
   regressed `Game.realT` and indexed before the sky palette, which is
   what threw in production.
2. **Sky-colour blending hardened.** `blend()`/`hex()` fall back to a
   default when a palette entry is missing instead of dereferencing
   `undefined`.
3. **KSC cache no longer poisons itself** (TECH_REVIEW BUG-4, actually
   fixed now). `checkedAt` is written only after a successful HTTP
   response and JSON parse; failed fetches retry next launch; non-OK
   HTTP throws instead of being parsed.

## Batch 1 — shipped in `shwape-v2.html` (2026-11-08)

`shwape-v2.html` = live build + the three repair patches + all five
approved creative changes. Verified in headless Chromium: all inline
scripts parse; live playtest confirmed dash decay-to-anchor, back-dash,
overdose death (`nikotin`), and boosted HUD at 844×390.

1. **Death screen: Dorfprotokoll / Schandbilanz.**
   `drawGeschäftsbericht()` and the entire BIN RUN INC. framing
   (Revenue/EBITDA/Kunden-Feedback) replaced by `drawDorfprotokoll()`:
   village minutes with Akte number, Schande / Gerede / Zeugen ledger
   lines, "WAS DAS DORF SAGT" verdicts, a Beschluss, and Frau Herta's
   stamp. The daily mutation now appears as "Wetter".
2. **Vape = life support, negative marginal returns.**
   Fresh drag (>2s gap): +8 Vape, +20 Aura. Chained drags escalate the
   dose by +6 per chain step (12, 18, 24, 30…), deliberately unclamped:
   >100% is the overdose zone (fast burn-off, HUD warning, screen
   shake), ≥125% (`CFG.VAPE_OD_LETHAL`) is instant death (cause
   `nikotin`, easter egg "Die Seele war zu voll."). The old full-tank
   flex-spam Aura farm is closed — a chained press at 99% now goes into
   the overdose path. Emergency floor (<6%: +4) kept, resets the chain.
3. **Difficulty: softer early, steeper late.**
   Vape drain base 1.6→1.35, ramp 0.05→0.03, plus a superlinear late
   kick after 4:00 (`VAPE_DRAIN_LATE_T` / `VAPE_DRAIN_LATE`). Base speed
   360→340; ramp ×0.65 before 2:30, ×1.5 after 5:00; speed ceiling
   climbs up to +90 after 5:00. Obstacle density: +0.55s grace decaying
   over the first ~90s, squeeze tightens to −0.55s after 5:00.
4. **Controls: dash directionality + camera lookahead.**
   Dash is directional: hold ← for a −150 back-dash (the only way back
   left); Mystery-pod inversion applies. `Player.x` is clamped both
   ways. New camera anchor: Bin Run eases toward
   `PLAYER_X − clamp((speed − BASE_SPEED)·0.32, 0, 90)`, so higher speed
   = more visible runway, and dashes decay back to the anchor instead of
   ratcheting right forever. (Old bug: the dash was the only `Player.x`
   writer besides `reset()`, so every dash permanently cost visibility.)
5. **Landscape-phone readability.**
   `resize()` computes `CFG.uiBoost = clamp(0.95/r, 1, 1.55)`; HUD
   surfaces scale with it: vape bar (incl. overdose flash + honest
   `VAPE n%` overshoot readout), score/time/combo, aura tier, notes,
   sigma/DM popups, insult cooldown pip, roast-chain banner, and the
   death-screen centre column. Death-screen touch-button *geometry* is
   unchanged because its hit tests are hardcoded to those rects.

Design invariant untouched: no win state added; the Mutter remains
unbeatable; insults unchanged.

## Tooling constraints discovered

- The GitHub token used by the AI session lacks the `workflow` OAuth
  scope: it cannot create/modify files under `.github/workflows/`.
  CI must be added by the owner or a token with that scope.
- The same token writes whole files only; the ~540 KB single-file game
  cannot be written through it. Large changes ship as: patch script +
  owner upload, or owner grants a workflow-scoped token.
- A 5-test static smoke pack (`node --test`) and a ready CI workflow
  exist in the AI session's deliverables; land them with the next big
  update.

## Design invariant (author's rule, binding)

The game is opt-in. If the player chooses insult and domination, loss
is inevitable; the final authority — the disappointed mother, shame —
is unbeatable. **No change may add a conventional win state.** Insults
stay as-is.
